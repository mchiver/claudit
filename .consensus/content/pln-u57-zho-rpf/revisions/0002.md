# Claudit Design I

A Claude Code plugin to expose the audit trail of a Claude Code session.

The plugin can be controlled within the session with `/claudit on` and `/claudit off`.

Git: https://github.com/mchiver/claudit

## Server

The plugin will wait on tool calls from Claude and publish them over a network connection.

**Session Hooks**
A hook on tool.call sees each call before it runs and after it finishes. For a shell call the description I write is right there on the event, and the clock gives the time. The mod records "hh:mm:ss description", marks the one in flight, and marks it done with its duration.

**Session Feedback**
When the turn ends, the mod can return a text block of tool call descriptions that Claude Code shows under the final response, so the timestamped list lands in the conversation and stays there.

**Session Archive**
Messages can be stored in local json files.

**API**
A web API to stream messages and also query archived messages.
