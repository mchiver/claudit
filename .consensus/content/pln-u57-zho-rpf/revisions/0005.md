# Claudit Design I

A Claude Code plugin to expose the audit trail of a Claude Code session.

The plugin is controlled within the session with `/claudit on`, `/claudit off` and `/claudit status`. It is on by default. The setting persists across sessions in the engine's cross-session store, so off stays off until the next on. `/claudit status` says whether it is on, the server's address and whether it answers, and the count of calls recorded this session.

Git: https://github.com/mchiver/claudit. The repo exists on GitHub; the working folder is initialised as the repo's root with that URL as the origin remote, and a .gitignore for node_modules and tilde-prefixed files. Git stays the owner's: the agent commits only when a build log is accepted, and never branches or pushes.

## Server

The plugin will wait on tool calls from Claude and publish them over a network connection.

**Session Hooks**
A hook on tool.call sees each call before it runs and after it finishes. For a shell call the description I write is right there on the event, and the clock gives the time. The mod records "hh:mm:ss description", marks the one in flight, and marks it done with its duration.

**Session Feedback**
When the turn ends, the mod can return a text block of tool call descriptions that Claude Code shows under the final response, so the timestamped list lands in the conversation and stays there.

**Session Archive**
Messages can be stored in local json files.
Messages are retained according to a retention policy.

**API**
A web API to stream messages and also query archived messages.
